# Target indicators starter assets

The starter assets contains a colletion of scripts, prefabs, and other assets to show how to use target indicators and as a starting point for customizing your own indicators.

The assets are grouped in two categories:

1. **Core Assets**

    Core assets are located in `Assets/Samples/Target Indicators/[version]/StarterAssets/Core Assets` and contains the set of scripts, prefabs, and textures for you to use as a foundation for your own visual indicators.

2. **Example Assets**

    Example assets are located in `Assets/Samples/Target Indicators/[version]/StarterAssets/Example Assets` and contains the scripts, prefabs, and other assets needed for the sample scenes.

> [!IMPORTANT]
> The **TextMeshPro Essentials** need to bee imported into your project for the text in the sample scenes to render. If you do not see text displayed in the samples scenes, you need to import the text mesh pro essentials. Navigate to **Window** > **TextMeshPro** > **Import TMP Essential Resources** and import.

Refer to the documentation to learn more about the [Samples](https://jakemanfre.github.io/target-indicators.github.io/manual/samples/samples.html).
